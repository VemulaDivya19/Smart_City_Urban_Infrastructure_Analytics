# 🏙️ Smart City Urban Infrastructure Planning & Analytics System

> **GIS | Python | Power BI | Urban Analytics**

## 📌 Project Overview

The **Smart City Urban Infrastructure Planning & Analytics System** is an end-to-end Business Intelligence project developed to analyze and visualize urban infrastructure data using **Python, Microsoft Power BI, Excel, and GIS concepts**.

The project demonstrates how data analytics can support urban planning by providing interactive dashboards that monitor infrastructure availability, distribution, and coverage.

---

## 🎯 Objectives

- Analyze urban infrastructure data.
- Monitor infrastructure availability across different categories.
- Visualize infrastructure distribution using Power BI.
- Generate insights for urban planning and decision-making.
- Demonstrate an end-to-end analytics workflow using Python and Power BI.

# ▶️ How to Run

1. Clone the repository.
2. Install the required Python libraries.

```
pip install -r requirements.txt
```

3. Run the Python scripts.

```
python main.py
```

4. Open the Power BI dashboard.

```
PowerBI/Smart_City_Urban_Infrastructure_Analytics_Dashboard.pbix
```
